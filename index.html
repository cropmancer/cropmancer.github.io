An economy that loops

Player rewards are paid from a Rewards Pool — funded by 50% of every registration plus creator fees from $MANCER trading. The Produce→$MANCER rate floats with the pool, so rewards never exceed what the pool holds. Upgrades recycle 90% back to the pool and burn 10% forever: the more people play, the scarcer $MANCER gets. Production is calculated server-side — the server is the referee, clock tricks do nothing.

Cropmancer is a game. $MANCER is a game token whose market price is set by traders and can go to zero. Registration buys a game access NFT — not an investment. There is no guarantee of any price, earnings, or return. Game parameters may be tuned before launch; material changes will be announced on the official channels.
